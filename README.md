# 我的记账

把**支付宝**和**微信**两边分散的账单合并到一起，自动分类，用图表看清"钱花在哪"。

- 纯前端网页 App（PWA），可加到手机主屏当图标用
- **数据全程在你手机本地处理，一个字节都不上传任何服务器**
- 每月导入一次账单做复盘，不需要后台实时监控

---

## 每月怎么用（核心流程）

1. 从支付宝导出 `.csv`、从微信导出 `.xlsx`（见下方导出步骤）
2. 打开 App → 进入「导入」页 → 选择这两个文件（可一次多选）
3. 自动回到「概览」页：看本月支出/收入/结余、分类饼图、每日支出
4. 进「明细」页：把高亮的「其他」项手动归类——**改一次，系统记住这个商户，以后自动归**
5.（可选）「导入」页点「导出备份」存一份 JSON，换设备或清缓存后可恢复

---

## 怎么导出账单

> 各 App 版本菜单位置可能略有变化，以下为大致路径，找不到时搜索"交易流水/账单下载"。

### 支付宝（导出 CSV）
1. 我的 → 账单 → 右上角「…」或「开具交易流水证明」
2. 选「用于个人对账」（不是打印版）
3. 选时间范围 → 发送到邮箱 → 下载得到 `.csv` 文件
4. 注意：支付宝 CSV 是 **GBK 编码**，本 App 已自动处理，无需你转码

### 微信（导出 xlsx）
1. 我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→「下载账单」
2. 选「用于个人对账」→ 选时间范围 → 填邮箱
3. 邮箱收到一个**加密压缩包**，解压密码会通过**微信支付公众号的消息**发给你
4. 用该密码解压，得到 `.xlsx` 文件，再导入本 App

## 自动分类说明

分类按优先级工作：

1. **商户记忆**（最高）：你手动归过类的商户，直接套用
2. **支付宝原始分类**：支付宝账单自带"餐饮美食/交通出行"等，直接映射
3. **关键词规则**：按商户名/商品说明匹配（美团→餐饮、地铁→交通…）
4. **兜底**：都不命中 → 归入「其他」并高亮，等你手动归类

真实账单实测自动归类率约 **90%**。剩下的多是**人名转账**——这类无法靠规则预测，手动归一次即可被记住。

分类体系（学生版）：餐饮 / 交通 / 购物 / 学习教育 / 娱乐休闲 / 话费通讯 / 生活缴费 / 医疗健康 / 人情往来 / 其他。
想增改分类或关键词，编辑 `js/classify.js`。

## 部署到手机（一次性）

App 需要部署到一个 HTTPS 网址才能安装为 PWA（`file://` 直接打开缺少安装与持久化能力）。

**方式 A：Netlify Drop（最简单，无需账号命令）**
1. 浏览器打开 https://app.netlify.com/drop
2. 把整个 `app` 文件夹拖进去，得到一个 HTTPS 网址
3. **拖之前务必确认文件夹里没有你的真实账单 csv/xlsx**（见隐私说明）

**方式 B：GitHub Pages**
推送到 GitHub 仓库 → Settings → Pages → 选分支根目录部署。

**装到主屏**：手机浏览器（Chrome/Safari）打开网址 → 菜单「添加到主屏幕」→ 桌面出现「记账」图标，点开全屏运行，断网也能开。

## 更新代码后看不到变化？（重要）

本 App 用 Service Worker 做离线缓存，它会**缓存旧版代码**。如果你改了代码（比如分类规则）却发现没生效：

1. 改完后把 `sw.js` 里的 `const CACHE = 'jizhang-v1'` 版本号改一下（如 `v2`），重新部署
2. 或在浏览器：DevTools → Application → Service Workers → Unregister，再刷新
3. 手机上：在 App 设置里清除该网站数据，或卸载主屏图标重装

## 隐私说明

- 所有解析、分类、统计、存储都在你手机浏览器本地完成（IndexedDB），**不联网、不上传**
- 部署到公开网址的只是**不含任何数据的程序代码**，不是你的账单
- 本仓库的 `.gitignore` 已排除所有 `.csv`/`.xlsx` 账单文件，**它们不会进入 git、不会被推到 GitHub**
- 想彻底清空：「导入」页 →「清空数据」

## 开发

```bash
node --test        # 跑纯逻辑单元测试（解析/去重/分类/统计）
npx serve .        # 本地起静态服务器预览（不要用 file:// 打开）
```

技术栈：HTML + 原生 JS(ES Module) + PapaParse(CSV) + SheetJS(xlsx) + Chart.js + IndexedDB。无构建步骤，改完刷新即生效。
